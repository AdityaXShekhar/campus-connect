# Campus Connect 🎓
**A Smart Campus Ecosystem | Connect • Trade • Grow**

Campus Connect is a comprehensive Academia-Industry collaboration web platform designed to streamline campus life. It integrates a secure second-hand marketplace, a dedicated career hub for skill mapping and internships, and robust core features to bridge the gap between students, companies, and administration.

## 🚀 Key Features Output

### 🛒 Second-Hand Marketplace
* **Buy / Sell Items:** Easy listing and browsing of academic and personal items.
* **Real-Time Price Comparison:** Get the best deals within the campus.
* **Filters & Search:** Quickly find exactly what you need.
* **Secure & Trusted Platform:** Safe transactions with integrated payment gateways.

### 💼 Career Hub (Career Portal)
* **Internships & Jobs:** Direct placement and internship opportunities.
* **Company Connect:** Direct networking between students and industry professionals.
* **Skill Resources & Mapping:** Tools to build and track professional skills.
* **AI-Powered Recommendations & Career Guidance:** Smart suggestions for tailored career paths.

### ⚙️ Core Features
* **Dynamic User Management:** Dynamic, role-based registration forms for Students, Companies, Admins, and Visitors.
* **Chat & Notifications:** Real-time communication and integrated email updates.
* **Night Mode & Analytics:** Dark mode toggle for accessible viewing, paired with built-in data insights.

## 🏗️ Project Architecture (Modern Full-Stack)

* **Frontend Layer:** React.js, HTML, CSS, JavaScript (Responsive Web & Mobile UI)
* **Backend Layer:** Node.js + Express.js (API Server)
* **Database Layer:** MongoDB (Data Storage & Backend Architecture)
* **External Services:**
  * **Email Service:** User notifications and alerts
  * **Cloud Storage:** Media and document uploads
  * **Maps Integration:** Google Maps / Leaflet interactive mapping API for campus navigation
  * **Payment Gateway:** Secure financial transactions

## 📊 Research & Methodology (PRISMA Framework)
The development of Campus Connect is backed by a rigorous study selection process to ensure a highly optimized ecosystem:
* **Identification:** 1,248 records initially identified from academic databases (IEEE, Google Scholar, Scopus, etc.).
* **Screening & Eligibility:** Filtered through strict relevance and full-text assessments.
* **Included Studies:** Refined down to 76 highly relevant sources driving the platform's core architecture and feature set.
